X-RAY FOR TWITTER

What's New

1.5
Oct 14, 2026

A toolbar popup, and fixes for results that got stuck or couldn't be clicked. Needs Chrome, Edge or Brave 130 or newer.

New

  • Toolbar popup. Click the X-Ray icon to see how to use it, open X, read what's new, or report a bug.

Improved

  • Steady pins and pills. The pin icon and result pill stay in place instead of scaling or moving when hovered, showing a soft color highlight instead.
  • Side info card. The details popup now opens to the right of the pill instead of covering the text above or below, and automatically moves to the left if there is not enough room.
  • Matching platform outlines. Result pills and their detail cards now share matching colored outlines and subtle glows (green for Android, blue for iOS and web) so you can tell platforms apart at a glance.

Fixed

  • No more stuck "Locating...". If X doesn't answer within 10 seconds, the pill shows "Not available" for a moment and then turns back into a pin you can click to try again.
  • Results work right away. Right after a location appears, you can hover it for details and click it to copy, without reloading the page.
  • Safer results. Locations and app names from X are always shown as plain text, so they can never add buttons, links or anything else to the page.
  • No more fake results. X-Ray now only accepts a location from its own lookup, for the account you clicked, so other scripts on X can't show fake locations or interrupt a lookup.
  • X keeps its own protections. X-Ray used to switch off X's safety settings on every X page shown inside a frame. Now it only allows the one profile page it looks up to load in its hidden frame, and leaves everything else as X intended.
  • Saved results now expire. Locations you looked up are kept for 90 days from when you looked them up, up to 10,000, instead of piling up forever.
  • Two X tabs no longer erase each other's results. A lookup in one tab no longer wipes out results saved in another.
  • Your lookups stay private. Saved results now live in X-Ray's own storage, so X can no longer see which accounts you looked up. Results you already had are moved over automatically.
  • One odd result can't hide all pins. If X ever sends something unexpected for one account, only that account shows as unknown; every other post still gets its pin.
  • The right flag for every country. Flags now match the full country name, so Belarus no longer shows the US flag and Canada, Mexico and the Caribbean get their own flags. Over 250 countries and territories are covered, and accounts based in Europe get the EU flag.
  • No more doubled store country. An app store country such as "Russia App Store" now shows as just its flag, and the info card spells country names properly.
  • No more stuck "Copied!" message. Clicking a result pill twice quickly no longer leaves it stuck showing "Copied!", accounts with no location copy as unknown instead of undefined, and "Copied!" only appears when copying succeeded.
  • Works with the keyboard. You can Tab to the pin and result pills, press Enter or Space to use them, see where focus is, and screen readers now read out each button's name and the lookup result.
  • Pin hint stays on screen. The "Get Location & App Store" hint now stays inside the window near the right edge, goes away if X removes the post you were pointing at, and no longer pops up over a pill that is already looking up.
  • No more errors inside X's frames. X-Ray no longer tries to read downloads and other non-text answers while looking up a profile, which used to cause error messages in the page's console.
  • Smoother scrolling. X-Ray now only checks new posts, and does it once per screen refresh, instead of re-checking every post on the page each time anything on X changes.
  • Lighter on your computer. The glowing border on result pills now only moves while you hover over a pill, instead of spinning on every pill all the time. If your system is set to reduce motion, pill animations are turned off.
  • App store regions are named. When an account's app store is in a region and not a country, such as "South Asia", the info card now shows that name, matching the result pill, instead of "Unknown".
  • Tidier info card. The details card no longer shows a stray dot when an account has no app info, always stays inside the window, and disappears when X removes the post you were hovering.
  • Every account name works. Accounts with names like "constructor" or "toString" no longer show "Unknown Loc" right away, and can be looked up like any other account.
  • No leftover hidden frame. X-Ray's hidden lookup frame is now removed from the page as soon as a lookup finishes or times out, instead of staying until you close the tab.
  • Only your clicks count. A script on X can no longer click every pin for you to start many lookups in the background, or copy from a result pill. Only a real click or key press works.
  • Odd page elements can't switch X-Ray off. A script on X that adds an element with a name X-Ray used to look for can no longer hide every pin or get the info card written into its own element.
  • Flags stay private. Country flags are now built into X-Ray instead of loaded from another website, so nobody else can see your IP address or which countries you look up.
1.0
Dec 3, 2025

First release.

New

  • Location on demand. Click the pin next to any post to see where the account is based and which app it posts from.
  • Country flags. Locations show with their country flag.
  • One-click copy. Click a result to copy it.
  • Remembers results. Locations you looked up show instantly next time, for up to 30 days.
