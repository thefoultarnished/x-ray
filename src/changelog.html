v1.5 Oct 14, 2026

A toolbar popup, and fixes for results that got stuck or couldn't be clicked. Needs Chrome, Edge or Brave 130 or newer.

New
Toolbar popupClick the X-Ray icon to see how to use it, open X, or read what's new.
Improved
New logoX-Ray has a fresh icon: a blue bird with a location pin on a dark rounded square.
Steady pins and pillsThe pin icon and result pill stay in place instead of scaling or moving when hovered, showing a soft color highlight instead.
Side info cardThe details popup now opens to the right of the pill instead of covering the text above or below, and automatically moves to the left if there is not enough room.
Matching platform outlinesResult pills and their detail cards now share matching colored outlines and subtle glows (green for Android, blue for iOS and web) so you can tell platforms apart at a glance.
Fixed
No more stuck "Locating..."If X doesn't answer within 10 seconds, the pill shows "Not available" for a moment and then turns back into a pin you can click to try again.
Results work right awayRight after a location appears, you can hover it for details and click it to copy, without reloading the page.
Safer resultsLocations and app names from X are always shown as plain text, so they can never add buttons, links or anything else to the page.
No more fake resultsX-Ray now only accepts a location from its own lookup, for the account you clicked, so other scripts on X can't show fake locations or interrupt a lookup.
X keeps its own protectionsX-Ray used to switch off X's safety settings on every X page shown inside a frame. Now it only allows the one profile page it looks up to load in its hidden frame, and leaves everything else as X intended.
Saved results now expireLocations you looked up are kept for 90 days from when you looked them up, up to 10,000, instead of piling up forever.
Two X tabs no longer erase each other's resultsA lookup in one tab no longer wipes out results saved in another.
Your lookups stay privateSaved results now live in X-Ray's own storage, so X can no longer see which accounts you looked up. Results you already had are moved over automatically.
One odd result can't hide all pinsIf X ever sends something unexpected for one account, only that account shows as unknown; every other post still gets its pin.
The right flag for every countryFlags now match the full country name, so Belarus no longer shows the US flag and Canada, Mexico and the Caribbean get their own flags. Over 250 countries and territories are covered, and accounts based in Europe get the EU flag.
No more doubled store countryAn app store country such as "Russia App Store" now shows as just its flag, and the info card spells country names properly.
No more stuck "Copied!" messageClicking a result pill twice quickly no longer leaves it stuck showing "Copied!", accounts with no location copy as unknown instead of undefined, and "Copied!" only appears when copying succeeded.
Works with the keyboardYou can Tab to the pin and result pills, press Enter or Space to use them, see where focus is, and screen readers now read out each button's name and the lookup result.
Capital letters don't matter"@SpaceX" and "@spacex" are now the same account, so they share one result and are looked up once.
Pin hint opens above near the bottomWhen a pin is close to the bottom of the window, its hint now opens above the pin instead of being cut off.
Faster savingX-Ray no longer rereads every saved location after each lookup. Old and extra results are cleared once when X loads instead.
Escape closes the hint and the cardWhen a pin or result pill has keyboard focus, pressing Escape hides its hint or info card without moving focus away.
Web accounts show their countryFor accounts that use the web app, the info card's Platform row now shows their location with its flag, such as "Peru · Web", instead of "Unknown".
Clean copied textIf X sends an account's app name as a link, copying a result now gives you just the words, such as "Peru (Twitter for iPhone)", with no code around it.
Lighter on X's other framesOnly the main X page now loads X-Ray's flags, script and styles. Other frames on X get just one tiny script, so they no longer each load the whole extension.
No double lookupsIf you click a pin while the same account is already being looked up, the new pin now joins that lookup instead of sending a second request to X. Posts that appear during a lookup show "Locating..." right away.
No pins that can't workX-Ray now adds a pin only when a post's name link is a real account name, so posts with other kinds of links no longer get a pin that ends on "Not available".
Pin hint stays on screenThe "Get Location & App Store" hint now stays inside the window near the right edge, goes away if X removes the post you were pointing at, and no longer pops up over a pill that is already looking up.
No more errors inside X's framesX-Ray no longer tries to read downloads and other non-text answers while looking up a profile, which used to cause error messages in the page's console.
Smoother scrollingX-Ray now only checks new posts, and does it once per screen refresh, instead of re-checking every post on the page each time anything on X changes.
Lighter on your computerThe glowing border on result pills now only moves while you hover over a pill, instead of spinning on every pill all the time. If your system is set to reduce motion, pill animations are turned off.
App store regions are namedWhen an account's app store is in a region and not a country, such as "South Asia", the info card now shows that name, matching the result pill, instead of "Unknown".
Tidier info cardThe details card no longer shows a stray dot when an account has no app info, always stays inside the window, and disappears when X removes the post you were hovering.
Every account name worksAccounts with names like "constructor" or "toString" no longer show "Unknown Loc" right away, and can be looked up like any other account.
No leftover hidden frameX-Ray's hidden lookup frame is now removed from the page as soon as a lookup finishes or times out, instead of staying until you close the tab.
Only your clicks countA script on X can no longer click every pin for you to start many lookups in the background, or copy from a result pill. Only a real click or key press works.
Odd page elements can't switch X-Ray offA script on X that adds an element with a name X-Ray used to look for can no longer hide every pin or get the info card written into its own element.
Flags stay privateCountry flags are now built into X-Ray instead of loaded from another website, so nobody else can see your IP address or which countries you look up.
